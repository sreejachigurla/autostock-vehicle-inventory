# How AI Was Used

ChatGPT was used as a development assistant throughout the project for:

* Understanding and structuring the full-stack application.
* Generating and explaining backend boilerplate.
* Implementing REST API routes and controllers.
* Implementing JWT-based authentication and authorization.
* Designing MongoDB models.
* Debugging Node.js, npm, dependency, and Vite issues.
* Developing and improving React components.
* Improving the CSS and overall user interface.
* Understanding Git and GitHub commands.
* Creating project documentation.

All generated suggestions were reviewed, integrated, tested, and adjusted during the development process.

---

# AI Usage Reflection

ChatGPT helped accelerate the development process by providing explanations, debugging assistance, implementation guidance, and UI suggestions. It was especially useful when resolving development environment issues and structuring different parts of the full-stack application.

AI was used as an assistant rather than a replacement for the development process. The project was assembled, configured, tested, debugged, and integrated manually during development.

This file is included to maintain transparency regarding the use of AI in the project development workflow.
